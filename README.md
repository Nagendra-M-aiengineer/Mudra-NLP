# Mudra NLP - Multilingual Bharatanatyam Mudra Classification & Explanation System

An NLP-powered multilingual classification system for classical **Bharatanatyam Mudras (Hastas)**. Built with high-fidelity semantic matching, speech recognition, audio narration, and full explanations in **English, Kannada (ಕನ್ನಡ), Tamil (தமிழ்), Telugu (తెలుగు), Malayalam (മലയാളം), and Hindi (हिन्दी)**.

---

## 🪷 Features

- **35+ Classical Hastas**: Comprehensive coverage of Asamyuta (single hand) and Samyuta (combined hand) mudras codified in the ancient treatise *Abhinaya Darpana* and *Natya Shastra*.
- **Multilingual NLP Engine**: Classifies descriptive queries in natural language across 6 languages with tokenization, weighted n-gram matching, and confidence estimation.
- **Full Multilingual Explanations**:
  - Mudra Name (English, Sanskrit Devanagari, and Native Script)
  - Mudra Type (Asamyuta / Samyuta Hasta)
  - Meaning & Symbolism (Viniyoga) in the selected language
  - Step-by-Step Hand Formation instructions in the selected language
  - Dramatic Dance Usages in the selected language
  - Sanskrit Shloka from *Abhinaya Darpana*
- **Instant Language Switching**: Dynamic tabs on the prediction card allowing instantaneous re-translation between English, Kannada, Tamil, Telugu, Malayalam, and Hindi.
- **Voice Input (STT)**: Hands-free voice recognition with regional Indian accents.
- **Text-to-Speech (TTS)**: Audio narration that vocalizes the mudra explanation aloud in the selected language.
- **Vector Hand Gesture Illustrations**: Embedded SVG illustrations featuring classical temple jewellery and red *Alta/Marudhani* dye.
- **Interactive Mudra Catalog**: Searchable and filterable repertory of all single and double hand mudras.
